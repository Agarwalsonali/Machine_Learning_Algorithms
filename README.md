# Machine Learning Algorithms

A collection of beginner-friendly Machine Learning algorithms implemented using **Python**, **NumPy**, **Pandas**, and **Scikit-learn**. This repository contains Jupyter notebooks and Python scripts demonstrating the implementation of fundamental supervised learning algorithms along with practice questions.

---

## 📌 Overview

This project is designed to help understand the basics of Machine Learning by implementing popular algorithms on real datasets. Each notebook walks through data preprocessing, model training, prediction, and evaluation.

---

## 🚀 Algorithms Included

- 📈 Simple Linear Regression
- 📊 Multiple Linear Regression
- 🔐 Logistic Regression
- 🌳 Decision Tree Classifier
- 🌲 Random Forest Classifier
- 👥 K-Nearest Neighbors (KNN)
- 📧 Naive Bayes Classifier

## ⚙️ Installation

### Clone the repository

```bash
git clone <repository-url>
cd Machine_Learning_Algorithms
```

### Install dependencies

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

---

## ▶️ Running the Project

### Open Jupyter Notebook

```bash
jupyter notebook
```

Then open any notebook such as:

- `SimpleLinearRegression.ipynb`
- `DecisionTree.ipynb`
- `LogisticRegression.ipynb`

To run the Python script:

```bash
python RandomForests.py
```
